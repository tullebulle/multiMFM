  Old GLASS value estimator:

  X1_samples = glass_integrate(

  New MFM value estimator:

  I = randn(B * N, D)

  for s0, s1 in posterior_grid:
      I = mfm.X(

          u=s1,
          x=I,
          t_cond=t,
          x_cond=x_t_repeated,
      )

  X1_samples = I
  V_t(x_t) = logmeanexp(r(X1_samples))

  So instead of integrating GLASS for, say, 8-20 Euler steps, we use the trained MFM map with 1, 2, or 4 posterior steps.
