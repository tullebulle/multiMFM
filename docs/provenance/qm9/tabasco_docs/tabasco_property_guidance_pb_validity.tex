QM9 guidance retained $90.3$--$92.3\%$ PoseBusters validity across the six
properties, compared with $98.7\%$ for unsteered generation. For the selected
GEOM-Drugs fingerprint-guidance evaluation, validity remained $87.5\%$
($56/64$ molecules) while mean Tanimoto similarity increased from $0.2072$
to $0.2272$. The paired unsteered Tanimoto value here is the measured baseline
for this run; it is distinct from the $0.170$ random-generation reference
listed in the paper's comparison table.
